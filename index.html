    Printing Notes

    • Print in landscape orientation.
    • Print at 100% / Actual Size.
    • Do not use "Fit to page" if it changes scale.
    • Fold on guide lines, cut the center slit, then fold into the mini-zine.

    Page (Image Notes)

    • Actual page image size is 2.75 in x 4.25 in.
    • That equals 825 x 1275 px at 300 DPI.
    • 4 x 6 photo source images also work nicely.
    • Use portrait-oriented source images for best fit.
    • Contain mode keeps the full image visible without cropping.
    Supported input: PNG, JPG/JPEG, WebP. Unsupported files are ignored.
